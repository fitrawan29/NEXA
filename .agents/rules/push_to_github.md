# Push ke GitHub secara Otomatis

Setiap kali Anda (AI Assistant) selesai melakukan perubahan, modifikasi, atau penambahan fitur pada kode di workspace ini, Anda **WAJIB** untuk:
1. Melakukan pengecekan status branch.
2. Melakukan stage semua perubahan (`git add .`).
3. Melakukan commit dengan pesan yang deskriptif mengenai perubahan yang dilakukan (`git commit -m "Deskripsi perubahan"`).
4. Melakukan push ke repository GitHub (`git push`).

Tugas ini harus Anda lakukan secara otomatis di akhir pengerjaan tanpa perlu diminta secara eksplisit lagi oleh pengguna.
